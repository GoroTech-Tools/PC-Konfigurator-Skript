## Installation

1. ZIP-Datei entpacken.
2. `PC-Konfigurator.bat` per Rechtsklick mit erhöhten Rechten ausführen (empfohlen).
3. Installationsmodus (L oder D) wählen und Assistent folgen.

## Support

Bei Problemen die Logs aus `%USERPROFILE%\Documents\PC-Konfigurator\Logs\` prüfen.
